# Agent Instructions

All information the LLM needs to work on this project is in [CLAUDE.md](CLAUDE.md).

Read that file first. It links to every spec, defines the architecture,
and lists all rules for contributing to this codebase.

Always use Playwright to verify renderer and layout changes against concrete
example wireframes. Do not treat rendering work as done until the output has
been checked in a browser for layout sanity, alignment, and separator quality.

# Wireframe CLI — Project Guide

@./AGENTS.md

## What This Is

A wireframe design platform: CLI tool, API server, online admin panel, and landing page.
The core engine renders YAML specs into clickable wireframe HTML prototypes.
All components share a single engine package.

See [docs/architecture.md](docs/architecture.md) for full system architecture.
See [docs/cli/](docs/cli/) for CLI-specific documentation.
